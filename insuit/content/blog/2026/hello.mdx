The blog starts here. Each post is an MDX file in `content/blog/<year>/`, its
name the address: this one is `2026/hello.mdx`, at `/blog/hello`. It is hidden,
so the list leaves it out; it stays for the tests, and to show what a post can
hold.

## A video

MDX is markdown that takes JSX, so a post can hold a component. This video, for
one, loads nothing from YouTube until it is played. You have been warned:

## Typography

Everything below is here to see how the text looks: headings, lists, quotes,
code and a table.

### A third-level heading

A paragraph with **bold**, _italic_, ~~struck through~~, `inline code`, a
[link within the site](/cv) and a [link out](https://example.com/). Long words
and addresses wrap: https://www.example.com/a/rather/long/address/that/has/to/wrap.
