Setup

pollos is my homelab — a small cluster of Debian 13 boxes where every node is named after a Breaking Bad character (walter, jesse, mike, gus…). Pretty hostnames make each box easy to spot and a joy to SSH into. The scripts below take a fresh Debian install and turn it into another member of the family.

For the OS install I recommend Ventoy — drop the Debian ISO (and any others you want) on a USB stick once, then boot whichever one you need on demand.

Steps

Only the first two happen at the box. Everything after runs over SSH from the laptop, so the long tokens and keys are pasted from the clipboard, never typed.

1. Install Debian 13. Name the host after the character, and in Software selection tick SSH server. The user the installer asks for is containers.

2. At the box, read its address — the one thing copied off the screen:

ip -4 a

3. From the laptop, log in with the installer's password and become root: 

ssh containers@192.168.0.x
su -

4. Run the scripts in order. Minimal Debian ships wget, not curl. The ones that ask nothing can be piped: 

wget -qO- https://pollos.cz/init.sh | sh
wget -qO- https://pollos.cz/users.sh | sh

From here on, log in as ansible with the key and use sudo:

ssh -i ~/.ssh/id_ed25519_homelab ansible@192.168.0.x
wget -qO- https://pollos.cz/docker.sh | sudo sh
wget -qO- https://pollos.cz/typescript.sh | sudo sh

The two that need a secret ask for it, so download them and run them in the terminal — a pipe has no terminal to ask on. Paste the tunnel token from Cloudflare → Networking → Tunnels → health-<host>, and an auth key from Tailscale → Settings → Keys tagged tag:pollos: 

wget https://pollos.cz/monitoring.sh && sudo sh monitoring.sh
wget https://pollos.cz/tailscale.sh && sudo sh tailscale.sh
rm monitoring.sh tailscale.sh

5. Done. The box is on the tailnet, reachable by name from anywhere:

ssh saul.pollos
