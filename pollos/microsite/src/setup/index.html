Setup

pollos is my homelab — a small cluster of Debian 13 boxes where every node is named after a Breaking Bad character (walter, jesse, mike, gus…). Pretty hostnames make each box easy to spot and a joy to SSH into. The scripts below take a fresh Debian install and turn it into another member of the family.

For the OS install I recommend Ventoy — drop the Debian ISO (and any others you want) on a USB stick once, then boot whichever one you need on demand.

Download & run

Minimal Debian ships with wget but not curl, so use wget for the first bootstrap. Examples below use {{EXAMPLE_ALIAS}}; swap in any short URL from the listing.

Inspect a script in the terminal:

wget -qO- https://pollos.cz/{{EXAMPLE_ALIAS}} | less

Download to disk (saves as {{EXAMPLE_ALIAS}}):

wget https://pollos.cz/{{EXAMPLE_ALIAS}}

Run directly as root on a fresh Debian box:

wget -qO- https://pollos.cz/{{EXAMPLE_ALIAS}} | sudo bash
